# HızlıFatura

İki kişi tarafından sıfırdan geliştirilecek fatura projesinin başlangıç deposu

Şu anda uygulama kodu veya seçilmiş bir teknoloji altyapısı bulunmuyor. Yeni kapsamı ve geliştirme adımlarını birlikte belirleyeceğiz.

Önceki çalışmalardan kalan bağlam, ileride hatırlamak için [önceki aşamalar notunda](docs/onceki-asamalar.md) saklanıyor. Bu not yeni projenin kesin gereksinim listesi değildir.

Depo özeldir. Depo sahibi, **Settings → Collaborators → Add people** bölümünden diğer geliştiricinin GitHub kullanıcı adını ekleyerek erişim verebilir. Özel depo bağlantısı tek başına erişim sağlamaz.
